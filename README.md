# Awesome Behavior Datasets
Open-source datasets for animal behavioral video analysis: lab rodents to wild herds, single animals to colonies of thousands, and behavior video combined with neural recordings (e.g., in vivo calcium imaging), audio, depth or 3D motion capture.

## Summary

**199 datasets** are listed below. Every dataset name in this section links to its entry in the [Datasets](#datasets) tables.

* ⭐ marks datasets mentioned in our papers.
* **Individuals** means the number of animals recorded together in one video or session; the total number of distinct animals is shown in small text when known.
* The previous version of this list (up to 2023-07-25) is kept on the [`2023-07-25`](https://github.com/JackieZhai/awesome-behavior-datasets/tree/2023-07-25) branch.
